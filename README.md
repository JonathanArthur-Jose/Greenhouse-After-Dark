
# Greenhouse After Dark

## Project Description

Greenhouse After Dark is a space-themed text adventure and survival game developed using Python.

The game takes place aboard the space station Eden's Wake, orbiting the uninhabitable planet Vespara in the year 2189.

The player is responsible for maintaining Greenhouse Sector 7, where the station's oxygen-producing plants are mysteriously dying.

The player must investigate unusual events, examine plants, make decisions, and restore oxygen production while avoiding unnecessary noise and attention.

## Running the Program

To run the game:

1. Install Python 3.
2. Download or clone this GitHub repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```

Follow the instructions displayed in the terminal.

## Game Objective

The player's objective is to restore the station's oxygen production by identifying problems within the greenhouse and making appropriate decisions.

Players must manage the oxygen supply, protect the plants, and avoid making too much noise.

## Win Condition

The player wins by restoring oxygen production and keeping the greenhouse operational.

## Lose Condition

The player loses if the oxygen supply becomes critically low or the greenhouse can no longer support the station.
